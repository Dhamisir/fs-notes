# Food Delivery Platform

Build a food delivery website where users can **find nearby restaurants, explore their menus, and order food online**.

The main focus of the application is helping users quickly find restaurants based on their location, food preferences, ratings, delivery time, and other useful information.

## UI reference

Use the following restaurant-listing design as the visual reference for your application.

![Food delivery restaurant listing desktop UI](/food_delivery_restaurant_listing_desktop_ui.png)

## Customer features

Users should be able to:

- Find restaurants near their location
- Search for restaurants, dishes, or cuisines
- Filter restaurants by category, rating, delivery time, and other useful options
- Open a restaurant and view its menu
- Select food items and add them to the cart
- Review their cart and place an order
- Provide a delivery address
- View their current and previous orders
- Track the status of an order

## Restaurant owner features

Restaurant owners should be able to:

- Create and manage their restaurant profile
- Add, edit, and remove menu items
- Mark menu items as available or unavailable
- View incoming orders
- Update an order's status

## Technical requirements

Build the complete system using:

- **Frontend:** React with JavaScript
- **Backend:** Node.js and Express
- **Database:** MySQL

Decide how the frontend, backend, and database should work together. Design the database tables and REST APIs needed to support customers, restaurant owners, restaurants, menu items, carts, addresses, and orders.
